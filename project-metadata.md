# Project Metadata

- Project Title: Subagent Orchestration Demo
- Project Description: A demo project showcasing orchestrated subagent workflows for modernizing legacy PHP procedural CRUD (mysqli) into a strict layered Laravel 11+ API architecture (Model → DTO → Repository → Service → Controller).
